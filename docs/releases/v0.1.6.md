## English

### Legacy `.xls` support

- Detects added, modified, deleted, and renamed `.xls` files in Git commits, including uppercase
  extensions.
- Compares text, numbers, dates, booleans, worksheet changes, and hidden worksheet/row/column state.
- Reuses the existing 384 MB in-memory workbook snapshot cache for repeated `.xls` reviews.
- Rejects invalid, encrypted, or oversized legacy workbooks with a readable error.

> [!NOTE]
> Legacy `.xls` files expose the last saved formula result rather than formula source text. `.xlsx`
> files continue to compare formula text.

## 简体中文

### 新增旧版 `.xls` 支持

- 能识别 Git 提交中 `.xls` 文件的新增、修改、删除和重命名，扩展名不区分大小写。
- 支持比较文本、数字、日期、布尔值、工作表变化，以及隐藏工作表、行和列状态。
- 重复查看 `.xls` 时复用现有的 384 MB 进程内工作簿快照缓存。
- 损坏、加密或超过安全大小限制的旧版工作簿会显示可读错误，不会导致程序崩溃。

> [!NOTE]
> 旧版 `.xls` 只能读取最后保存的公式计算结果，无法读取公式原文；`.xlsx` 仍然比较公式文本。
