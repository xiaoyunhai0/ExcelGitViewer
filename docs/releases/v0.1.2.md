## English

### Simpler and faster history loading

- Removed changed-file scanning from initial commit-history loading.
- Loads only bounded commit metadata at startup and queries `.xlsx` paths after a commit is
  selected.
- Removed the separate “Excel-only commits” mode and its extra filtering state.
- Keeps persistent history caching and manual Refresh behavior.

This release prioritizes immediate commit-list display and avoids doing workbook-related Git work
before the user selects a commit.

## 简体中文

### 简化并加速提交记录加载

- 初次读取提交记录时不再扫描每条提交修改过的文件路径。
- 启动时只读取有界的提交元数据，选中提交后才查询其中变化的 `.xlsx` 文件。
- 移除“仅 Excel 提交”模式以及相关筛选状态。
- 保留持久化历史缓存和手动“刷新”行为。

这个版本优先让提交列表立即显示，用户选中提交前不再提前执行 Excel 相关 Git 查询。
