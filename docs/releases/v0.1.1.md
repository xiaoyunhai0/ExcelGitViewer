## English

### Faster repeat startup

- Added a persistent commit-history cache keyed by repository, HEAD, and scan limits.
- Restores the last successfully opened repository after restarting the application.
- Reuses cached history when HEAD is unchanged and automatically rebuilds stale or invalid cache
  data.
- Added an explicit Refresh action that bypasses the cache and scans Git again.
- Bounded history scanning to the latest 1,000 non-merge commits and displayed at most 200 records.

## 简体中文

### 加速重复启动

- 新增按仓库、HEAD 和扫描上限校验的持久化提交记录缓存。
- 退出并重新启动程序后，自动恢复上次成功打开的仓库。
- HEAD 未变化时直接复用缓存；缓存过期、损坏或字段异常时自动重新读取。
- 新增“刷新”操作，可明确绕过缓存并重新扫描 Git。
- 提交历史最多扫描最近 1,000 条普通提交，界面最多显示 200 条。
