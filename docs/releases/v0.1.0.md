## English

### Initial MVP

- Browse `.xlsx` changes from non-merge commits in a local Git repository without checking out
  files or changing branches.
- Detect added, modified, deleted, and renamed workbooks.
- Compare worksheet and cell additions, deletions, value changes, and formula text.
- Show nearby read-only context and flag hidden sheets, hidden rows/columns, and invisible
  whitespace.
- Parse workbooks in the background with cancellation and stale-result protection.
- Provide a packaged Windows x64 application that does not require Python.

Image differences, formatting differences, merge commits, and working-tree changes were outside
this initial milestone.

## 简体中文

### 首个 MVP 版本

- 只读浏览本地 Git 仓库普通提交中的 `.xlsx` 改动，不检出文件、不切换分支。
- 识别工作簿的新增、修改、删除和重命名。
- 比较工作表和单元格的新增、删除、值变化及公式文本。
- 显示差异单元格周边的只读上下文，并提示隐藏工作表、隐藏行列和不可见空白。
- 后台解析工作簿，支持取消任务并阻止过期结果覆盖当前选择。
- 提供无需安装 Python 的 Windows x64 打包版本。

图片差异、格式差异、合并提交和工作区未提交改动不在首个里程碑范围内。
