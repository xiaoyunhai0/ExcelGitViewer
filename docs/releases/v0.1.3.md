## English

### Stable background work and faster workbook review

- Fixed background worker lifetime handling so active Git and workbook tasks are not released too
  early.
- Added an in-memory LRU workbook snapshot cache with an approximate 384 MB budget.
- Reuses parsed snapshots when reviewing the same or adjacent workbook versions.
- Reduced the commit metadata window to the latest 200 non-merge commits.
- Strengthened cancellation and stale-result tests for rapid commit or file switching.

## 简体中文

### 稳定后台任务并加速工作簿审查

- 修复后台 Worker 生命周期，避免正在执行的 Git 或工作簿任务被过早释放。
- 新增约 384 MB 上限的进程内 LRU 工作簿快照缓存。
- 重复查看同一工作簿或相邻版本时直接复用已解析快照。
- 提交元数据读取范围调整为最近 200 条普通提交。
- 加强快速切换提交、文件时的取消和过期结果回归测试。
