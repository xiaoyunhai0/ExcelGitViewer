## English

### Customizable dock workspace

- Turned the six review areas into dockable panels that can be rearranged, tabbed, floated, and
  resized.
- Restores the panel arrangement after restart and adds Reset Layout for returning to the default
  workspace.
- Makes every table column manually resizable and supports double-click auto-fit.
- Persists widths for fixed-structure tables.
- Improved the project guide, ignored local workbook samples, and strengthened Linux/Windows UI
  checks for the packaged application.

## 简体中文

### 可自定义停靠工作区

- 六个审查区域改为可停靠面板，可重新排列、组合页签、浮动和缩放。
- 重启后恢复面板排列，并新增“恢复默认布局”以返回推荐工作区。
- 所有表格列宽均可手动拖动，双击列边界可以自动适配内容。
- 固定结构表格会记住列宽。
- 改进项目说明与本地样本忽略规则，并加强 Linux/Windows 打包程序的 UI 检查。
